# RK3506 网关 — 256MB Flash 空间占用精确估算

## 1. 两种场景对比

| 场景 | 说明 |
|------|------|
| **场景A: 有屏幕** | Qt Widgets + LinuxFB，带中文字体 |
| **场景B: 无屏幕** | Qt 纯后台逻辑，无 GUI |

---

## 2. 逐项拆解 — 场景A: 有屏幕

### 2.1 Loader 区

| 组件 | 大小 |
|------|------|
| SPL (Rockchip miniloader/TPL) | 200 KB |
| U-Boot (裁剪后) | 800 KB |
| U-Boot env | 64 KB |
| trust.img (ATF/OP-TEE) | 200~400 KB |
| **Loader 小计** | **~1.5 MB** |

### 2.2 内核区

| 组件 | 裁剪前 | 裁剪后 |
|------|--------|--------|
| zImage (压缩内核) | 8~12 MB | **3~4 MB** |
| DTB (设备树) | 60~100 KB | **40~60 KB** |
| 内核模块 (如全编入内核) | 10~30 MB | **0 MB** |
| **内核小计** | 18~42 MB | **~4 MB** |

### 2.4 压缩后大小

| 压缩方式 | 压缩率 | 压缩后大小 |
|----------|--------|-----------|
| SquashFS + XZ | ~45% | **~16 MB** |
| SquashFS + LZO | ~55% | **~19 MB** |
| UBIFS + ZSTD | ~50% | **~18 MB** |
| ext4 (不压缩) | 100% | **~35 MB** |

### 2.5 场景A 总计

| 分区 | 大小 | 说明 |
|------|------|------|

## 4. 进一步极限裁剪 (可选)

| 优化项 | 节省 | 代价 |
|--------|------|------|
| glibc → **musl** | 节省 ~2 MB | 少量兼容性问题 |
| 去掉 OpenSSL | 节省 ~2.5 MB | 无 HTTPS |
| 去掉 dropbear SSH | 节省 ~0.2 MB | 无远程登录 |
| 去掉 iptables | 节省 ~0.3 MB | 无防火墙 |
| 字体用 Unifont 替代 | 节省 ~3 MB | 字体不美观 |
| 内核用 LZ4 代替 XZ | 增加 ~0.5 MB 体积 | 启动快 1~2 秒 |
| 静态编译网关程序 (去掉动态库) | 可能省 ~2 MB | 灵活性降低 |

**极限裁剪后: 系统总占用可压缩到 ~10 MB (无屏)**

## 5. 256MB Flash 实际可用空间

### 5.1 SPI NAND 256MB

```
物理容量:                           256 MB
- 坏块预留 (出厂约2~5%):            - 8 MB
- UBI 管理开销 (约4~6%):            - 12 MB
- OOB 区域 (不计入用户数据):         - (已扣除)
─────────────────────────────────────
实际可用:                            ~236 MB
```

### 5.2 eMMC 256MB

```
物理容量:                           256 MB
- 分区表/GPT:                       - 1 MB
- Boot 分区 (预留):                 - 4 MB
─────────────────────────────────────
实际可用:                            ~251 MB
```

### 6.1 有屏幕方案 (SPI NAND)

│                256 MB SPI NAND                          │

│ userdata  │ 160 MB │ 网关配置、运行日志、OTA 升级包       │
